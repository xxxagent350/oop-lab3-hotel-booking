# Лабораторная работа №3 — Система бронирования отелей

**Группа:** СДП-ПИ-242  
**Авторы:** Лохницкий Михаил Илларионович, Коншин Илья Александрович

Консольное приложение на C# (.NET 9), демонстрирующее паттерны **Factory**, **Strategy** и **Observer**.

## Возможности

- Разные типы номеров с собственной ценой и вместимостью: `Standard`, `Deluxe`, `Suite`, `Family`.
- Тарифы расчёта стоимости: обычный, выходной, сезонный.
- Система скидок: длительное проживание, постоянный гость, композитная скидка.
- Поиск свободных номеров по типу, вместимости, максимальной цене и датам проживания.
- Бронирование: создание, подтверждение, отмена, проверка пересечения дат.
- Уведомления о событиях бронирования: e-mail, SMS и дополнительный канал — push.
- Статистика по типам номеров и текущий статус отеля.

## Паттерны

| Паттерн | Где применён |
|---|---|
| **Factory** | `RoomFactory` создаёт номера нужного типа, скрывая конкретные классы |
| **Strategy** | `IPriceStrategy` — тарифы, `IDiscountStrategy` — правила скидок |
| **Observer** | `Booking` — субъект, `IBookingObserver` — наблюдатели, `NotificationObserver` — адаптер к каналу уведомлений |

## Структура

```
HotelBookingSystem/
├── Models/          # номера, бронирование, статусы
├── Notifications/   # каналы уведомлений и Observer-адаптер
├── Services/        # RoomFactory, HotelManager, RoomFilter
├── Strategies/      # тарифы и скидки
└── Program.cs       # демонстрация всех возможностей
```

## Запуск

```bash
dotnet run --project HotelBookingSystem/HotelBookingSystem.csproj
```

или открыть `HotelBookingSystem.sln` в Visual Studio и нажать F5.
